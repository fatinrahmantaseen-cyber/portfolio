Featured Projects

1. BanglaShield

BanglaShield is a cybersecurity portfolio project focused on identifying potentially suspicious URLs and explaining their risk indicators.

The frontend uses Next.js, TypeScript, and Tailwind CSS. The backend uses FastAPI and Python to analyze URLs using deterministic heuristic rules.

  • URL scanning and risk assessment
  • Security dashboard and risk-analysis interface
  • Rule-based analysis without making network requests to scanned URLs
  • Backend validation and automated testing

This project helps me explore practical cybersecurity, API design, frontend development, and software testing.

2. ConnectSphere

ConnectSphere is a planned career and professional opportunity platform intended to help users discover jobs, understand career paths, and identify opportunities that match their skills.

Planned features include:

  • Job and internship discovery
  • Skill-based job matching
  • AI-assisted career guidance
  • Career development and skill recommendations
  • A platform designed with global opportunities in mind

The goal is to develop this idea into a complete full-stack application as I expand my software engineering and AI skills.
